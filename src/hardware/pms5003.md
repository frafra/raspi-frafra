## Collegamento

Il sensore si collega via UART. Ho scelto UART5 per non utilizzare la porta usata dal RaspBee II.

| UART | Raspberry Pi |
|------|--------------|
| NC   |              |
| NC   |              |
| RST  |              |
| RXD  | RXD5/GPIO12  |
| TXD  | TXD5/GPIO13  |
| SET  |              |
| GND  | GND          |
| VCC  | 5V           |

## Preparazione

1. Modificare `/boot/firmware/config.txt`, aggiungendo questa sezione alla fine del file:
   ```
   # Enable UART5 (PMS5003)
   dtoverlay=uart5
   ```

2. Riavviare il sistema con `reboot` e fare la verifica:

   ```bash
   timeout 3 cat /dev/ttyAMA5 | od -An -tx1
   ```
