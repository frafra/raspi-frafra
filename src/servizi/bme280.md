# Sensore BME280

Lo script legge il [BME280](../hardware/bme280.md) e pubblica le letture su MQTT; un timer lo esegue ogni minuto.

Servono il sensore già collegato e verificato (vedi [BME280](../hardware/bme280.md)), con `uv` installato, il broker [MQTT](mqtt.md) attivo e Podman con lingering ([Requisiti](../requisiti.md)).

## Script

`~/Code/bme280/publish.py`:

```python
#!/usr/bin/env -S uv run --script
#
# /// script
# requires-python = ">=3.13"
# dependencies = [
#     "paho-mqtt>=2.2.0",
#     "rpi-bme280>=0.2.4",
# ]
# ///

import json
import platform

import smbus2
import bme280
import paho.mqtt.client as mqtt

name = platform.node()

port = 1
address = 0x77

with smbus2.SMBus(port) as bus:
    calibration_params = bme280.load_calibration_params(bus, address)
    data = bme280.sample(bus, address, calibration_params)

client = mqtt.Client(mqtt.CallbackAPIVersion.VERSION2)
client.connect("127.0.0.1", 1883)
client.loop_start()

units = {
    "temperature": "°C",
    "pressure": "hPa",
    "humidity": "%",
}

for attr, unit in units.items():
    topic = f"{name}/bme280/{attr}"
    config_topic = f"homeassistant/sensor/{name}_bme280_{attr}/config"
    config = {
        "name": attr.capitalize(),
        "unique_id": f"{name}_bme280_{attr}",
        "state_topic": topic,
        "device_class": attr,
        "unit_of_measurement": unit,
        "state_class": "measurement",
        "device": {
            "identifiers": [f"{name}_bme280"],
            "name": "Raspberry Pi BME280",
            "manufacturer": "Bosch Sensortec",
            "model": "BME280",
        },
    }
    client.publish(config_topic, json.dumps(config), retain=True).wait_for_publish()
    client.publish(topic, round(getattr(data, attr), 2), retain=True).wait_for_publish()

client.disconnect()
client.loop_stop()
```

La prima esecuzione va fatta con la rete disponibile, perché uv deve scaricare i pacchetti:

```bash
chmod +x ~/Code/bme280/publish.py
~/Code/bme280/publish.py
```

Dopo la prima volta si può usare `uv run --offline`.

## Servizio

`~/.config/systemd/user/bme280.service`:

```ini
[Unit]
Description=Read BME280 and publish to MQTT

[Service]
Type=oneshot
ExecSearchPath=%h/.local/bin
ExecStart=uv run --offline %h/Code/bme280/publish.py
CacheDirectory=uv
Environment=UV_CACHE_DIR=%C/uv
Environment=PYTHONDONTWRITEBYTECODE=1
NoNewPrivileges=yes
UMask=0077
TimeoutStartSec=30
PrivateUsers=yes
ProtectSystem=strict
```

L'elenco completo delle opzioni è in [systemd.exec](https://www.freedesktop.org/software/systemd/man/latest/systemd.exec.html).


## Timer

`~/.config/systemd/user/bme280.timer`:

```ini
[Unit]
Description=Sample BME280 every minute

[Timer]
OnCalendar=*-*-* *:*:00
AccuracySec=1s
Persistent=true
Unit=bme280.service

[Install]
WantedBy=timers.target
```

## Attivazione e verifica

```bash
systemctl --user daemon-reload
systemctl --user enable --now bme280.timer
systemctl --user list-timers bme280.timer
journalctl --user -u bme280.service -n 20 --no-pager
```

Se `journalctl` non mostra errori, i dati dovrebbero essere su MQTT:

```bash
podman exec mosquitto mosquitto_sub -h 127.0.0.1 -t "$(hostname)/bme280/#" -v
```
