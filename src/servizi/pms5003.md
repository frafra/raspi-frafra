# Sensore PMS5003

Lo script legge il [PMS5003](../hardware/pms5003.md) e pubblica le letture su MQTT; un timer lo esegue ogni minuto.

Servono il sensore già collegato e verificato (vedi [PMS5003](../hardware/pms5003.md)), con `uv` installato, il broker [MQTT](mqtt.md) attivo e Podman con lingering ([Requisiti](../requisiti.md)).

## Script

`~/Code/pms5003/publish.py`:

```python
#!/usr/bin/env -S uv run --script
#
# /// script
# requires-python = ">=3.13"
# dependencies = [
#     "paho-mqtt>=2.2.0",
#     "pyserial>=3.5",
# ]
# ///

import json
import paho.mqtt.client as mqtt
import platform
import struct
from typing import NamedTuple

import serial


class PMS5003(NamedTuple):
    start: bytes
    length: int
    pm1_cf1: int
    pm25_cf1: int
    pm10_cf1: int
    pm1: int
    pm25: int
    pm10: int
    particles_03: int
    particles_05: int
    particles_10: int
    particles_25: int
    particles_50: int
    particles_100: int
    reserved: int
    checksum: int


FRAME = struct.Struct(">2s15H")

with serial.Serial("/dev/ttyAMA5", baudrate=9600, timeout=2) as ser:
    raw = ser.read(2 * FRAME.size)


start = raw.find(b"BM")
frame = raw[start : start + FRAME.size]
data = PMS5003(*FRAME.unpack(frame))

client = mqtt.Client(mqtt.CallbackAPIVersion.VERSION2)
client.connect("127.0.0.1", 1883)
client.loop_start()

name = platform.node()

pm_names = {"pm1": "PM1", "pm25": "PM2.5", "pm10": "PM10"}

for attr, value in list(data._asdict().items())[2:14]:
    topic = f"{name}/pms5003/{attr}"
    config_topic = f"homeassistant/sensor/{name}_pms5003_{attr}/config"
    config = {
        "unique_id": f"{name}_pms5003_{attr}",
        "state_topic": topic,
        "state_class": "measurement",
        "icon": "mdi:air-filter",
        "device": {
            "identifiers": [f"{name}_pms5003"],
            "name": "Raspberry Pi PMS5003",
            "manufacturer": "Plantower",
            "model": "PMS5003",
        },
    }
    if attr.startswith("pm"):
        pm = attr.removesuffix("_cf1")
        industrial = attr.endswith("_cf1")

        config.update(
            {
                "name": pm_names[pm] + (" (industrial)" if industrial else ""),
                "device_class": pm,
                "unit_of_measurement": "µg/m³",
                "enabled_by_default": not industrial,
            }
        )
    else:
        threshold = f"{int(attr.removeprefix('particles_')) / 10:g}"
        config.update(
            {
                "name": f"Particle count > {threshold} µm",
                "unit_of_measurement": "#/dL",
            }
        )

    client.publish(config_topic, json.dumps(config), retain=True).wait_for_publish()
    client.publish(topic, value, retain=True).wait_for_publish()

client.disconnect()
client.loop_stop()
```

La prima esecuzione va fatta con la rete disponibile, perché uv deve scaricare i pacchetti:

```bash
chmod +x ~/Code/pms5003/publish.py
~/Code/pms5003/publish.py
```

Dopo la prima volta si può usare `uv run --offline`.

## Servizio

`~/.config/systemd/user/pms5003.service`:

```ini
[Unit]
Description=Read PMS5003 and publish to MQTT

[Service]
Type=oneshot
ExecSearchPath=%h/.local/bin
ExecStart=uv run --offline %h/Code/pms5003/publish.py
CacheDirectory=uv
Environment=UV_CACHE_DIR=%C/uv
Environment=PYTHONDONTWRITEBYTECODE=1
NoNewPrivileges=yes
UMask=0077
TimeoutStartSec=30
PrivateUsers=yes
ProtectSystem=strict
```

L'elenco completo delle opzioni è in [systemd.exec](https://www.freedesktop.org/software/systemd/man/latest/systemd.exec.html).

## Timer

`~/.config/systemd/user/pms5003.timer`:

```ini
[Unit]
Description=Sample PMS5003 every minute

[Timer]
OnCalendar=*-*-* *:*:00
AccuracySec=1s
Persistent=true
Unit=pms5003.service

[Install]
WantedBy=timers.target
```

## Attivazione e verifica

```bash
systemctl --user daemon-reload
systemctl --user enable --now pms5003.timer
systemctl --user list-timers pms5003.timer
journalctl --user -u pms5003.service -n 20 --no-pager
```

Se `journalctl` non mostra errori, i dati dovrebbero essere su MQTT:

```bash
podman exec mosquitto mosquitto_sub -h 127.0.0.1 -t "$(hostname)/pms5003/#" -v
```
